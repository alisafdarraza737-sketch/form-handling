# 📝 React Form Handling

A beginner-friendly React project demonstrating how to manage form inputs and user data using React Hooks. This project explores controlled components, state management, input handling, and form submission.

## 🚀 Features

- **Name Input** – Accepts the user's name.
- **Address Input** – Collects address information.
- **Email Input** – Accepts email input.
- **React useState Hook** – Manages form data.
- **Controlled Components** – Keeps input values synchronized with React state.
- **onChange Event** – Handles input changes.
- **Form Submission** – Prevents default page reload and displays a submission alert.
- **Console Output** – Logs submitted form data.
- **Object-Based State** – Demonstrates managing multiple fields in one state object.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- React Hooks (`useState`)
- HTML5
- CSS3

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/alisafdarraza737-sketch/form-handling.git
```

2. Navigate to the project folder:

```bash
cd form-handling
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server (if configured with Vite):

```bash
npm run dev
```

## 📚 Concepts Practiced

### 1. useState Hook

Used to store and update form input values.

### 2. Controlled Components

Input fields use React state to manage their values.

### 3. Event Handling

The `onChange` event updates state whenever a user types.

### 4. Form Submission

The `onSubmit` event handles form submission and prevents the browser's default reload behavior.

### 5. Object State Management

The `filetwo.jsx` component demonstrates managing multiple form fields inside a single state object.
